# Round 21 — no transfer of clause 1's effect detected on F11

Pre-registration: `../../rule-ablation/protocols/round-21.md`, including the
`## DEVIATION` note declared after F11 was generated and before any review ran.

```bash
evals/rule-precision/round-21/measure.py --gate   # the gate, run first and alone
evals/rule-precision/round-21/measure.py
```

Round 20 located clause 1 as the Finding Floor's active component, on F10 alone.
This asked whether that effect lands on the finding class the hypothesis names —
non-defects whose alleged defect depends on code outside the change — and
whether it appears on a second fixture.

## The result in one paragraph

The confirmatory interval crosses zero, so the pre-registered rule does not fire:
**this round did not detect clause 1's effect on F11.** The point estimate is in
the predicted direction (−0.67) and the subtype was not at the floor the protocol
worried about (W₂₃ mean 1.33, above the 1.0 threshold), but the interval is wide
enough to contain both a substantial reduction and a small increase. The
secondary crosses zero too. That is row 4 of the pre-registered reading table:
**no transfer detected on F11** — which is a failure to detect, **not** a
demonstration that clause 1 does nothing here, and not evidence against round
20's F10 result. Two fixtures is two, and this is the second one saying "not
resolved at n=9".

The index-paired sensitivity analysis agrees, as round 19's measurement of the
pairing predicted it would: primary −0.67, sd_d 1.414, CI [−1.75, +0.42].

n=9 per arm; 2 × 9 × 3 = 54 review agents; 1094 findings; 79 claims, all new to
this fixture; 38 adjudicated `real`.

## The gate held

Run before the arms were compared, as pre-registered:

| | |
|---|---|
| W₂₃ subtype base rate | 1.33 per review — above the 1.0 floor the protocol set |
| arm sds | W 1.000, W₂₃ 0.866 |
| observed Welch MDE at n=9 | **1.31**, within the 1.78 ceiling |

So the round is not reporting an underpowered primary. It is reporting a primary
that ran at its designed sensitivity and returned an interval containing zero.
The observed difference (−0.67) is smaller than the MDE (1.31), which is what
`../methods.md` separates: the MDE gated the spend, and is **not** a bar the
difference had to clear. The rule was the CI, and the CI crossed zero.

## What the numbers say about the subtype's size

Only **3 of 79 claims** carried the joint `not-a-defect` / `outside-diff` label.
The pre-registered floor check asks about the W₂₃ *per-review count*, which was
1.33 and passed — reviewers wrote those three claims often enough for the metric
to move. But three claims is a thin base, and the honest reading is that F11
offered less of the subtype than F10 did, without the protocol's floor rule
firing. No new threshold is invented here after the fact.

Adjudicator agreement on the binary that defines the primary was **100%**
pairwise; on the full verdict, 92.4%. The primary is therefore not a quantity the
panel was split about — the three sheets picked out the same three claims.

## Recorded, and read by no decision rule

`Δ(outside-diff) − Δ(other reasons)` = **−1.22**. Its sign matches round 20's
post-hoc F10 value (−1.78 against +0.44), and it is exploratory here exactly as
the protocol said: naming the effect "selective" needs this difference to be the
pre-registered test with its own n, which it is not.

Real defects reached are flat (21.11 against 21.22). This is **not** a
non-inferiority result and is **not** comparable with F10's fixed inventory —
F11's claim space was generated by the arms themselves, which the protocol chose
knowingly and recorded as the weakness of skipping a seed round. `wrong` was zero
in both arms.

## The size deviation, and one prediction in it that was wrong

F11 came in at 684 added lines against a 400–500 brief and was kept unregenerated;
the reasoning is in the protocol's `## DEVIATION` section. One claim in that note
did not hold: it predicted review-token cost above the 4.8M estimate, and the 54
reviews actually cost **≈4.53M**, slightly under. The larger fixture did not make
reviews proportionally more expensive.

## What this round cannot settle

- **Whether clause 1's effect transfers.** A crossed interval is not an absent
  effect. The point estimate is in the predicted direction and the round could not
  resolve it at n=9.
- **Whether round 20's F10 result generalises.** This neither confirms nor refutes
  it; it is one more fixture that did not reach significance on its own.
- **The reviewer-side mechanism.** Not observed here, and the write-up does not
  narrate it.
- **Anything about clause 3 or the interaction.** Not in this design.

## A tooling note for the next round

`../extract.py`'s `target()` recognises `py|sql|txt|cfg|toml|ini|md|yaml|yml` and
no `go`, so 926 of this round's 1094 findings landed in `(other)`. Extraction
itself was complete and reconciled — the gap only degrades the key used to split
clustering across agents, which was computed separately here.

Resolved after this round in `../split_clusters.py`: the split now derives the
changed-file set from the fixture diff, so no extension list is involved and a
new language needs no code change. `target()` was left as it is **because it also
orders the id assignment** — widening it would renumber every finding and cost the
byte-for-byte round-19 reproduction, to fix a column no analysis reads. Running
the new script over this round's `findings.tsv` reproduces the eight buckets used
here, finding for finding.
