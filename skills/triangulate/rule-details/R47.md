# R47 — Surface-form adjudication where an interpreter defines the meaning

This file contains the full normative procedure for `R47`. The compact row in `../common-rules.md` is only its routing summary.

## Full rule

| ID | Pattern | Procedure | Severity if missed |
|---|---|---|---|
| R47 | Surface-form adjudication where an interpreter defines the meaning | Fires when a decision — a guard, gate, router, classifier, cache key — is made about an input whose *meaning* is fixed by a downstream interpreter: a path (the filesystem's resolver), a document's structure (the Markdown/HTML/YAML parser), a command line (the shell), a code identity (the compiler / type system / language service), a query (the SQL engine), a location (the URL parser). Judging the *notation* — normalizing the string, matching a regex over raw text, enumerating known spellings — reimplements the interpreter approximately, and the approximation is open by construction: every unlisted spelling of the same meaning is a bypass, and the guard then grows by one round per reported spelling. Two observed sequences, each a single equivalence class discovered one member at a time: doubled separator, then dot segment, then parent segment, then leaf symlink, then directory symlink plus parent segment, then a symlinked home root, then the literal home shorthand; and backtick fence, then tilde fence, then HTML comment. **Do**: resolve the input through the mechanism the runtime itself uses and judge the RESULT — physical resolution per component (lstat, symlink chains followed) for paths; a parser's node or state for a document; the language's own toolchain (compiler API, declaration emitter, type checker) for code identity; an argument vector rather than string inspection for commands. Authority ladder, weakest first: raw text, normalized text, your own partial parser, the actual interpreter's output. Climb to the highest available rung before shipping, not after the third bypass — the trigger to stop patching is the FIRST bypass whose fix is another spelling (this is R42 clause ①b applied to an input space instead of a member set). **Sub-clauses**: (a) when the interpreter cannot be consulted at decision time (a static gate over untrusted source, an input the parser refuses), the control is not a boundary — declare it under R49 and deny the unresolved case rather than guessing from notation; (b) the resolved decision must cover the not-yet-existing subject too (resolve the nearest existing ancestor, since a path that does not exist has no physical resolution) — a create-path is where notation checks are usually left in place; (c) a notation check may remain as a cheap pre-filter only if it can NARROW the authoritative decision and never produce a verdict of its own (see R48). **Distinct from**: R42 (closes a member-set by derivation over code; R47 closes an input-space by delegation to an interpreter — R42's axis enumeration is the fallback for input spaces no interpreter decides), RT7 shape (f) (the same ladder written for AST classifiers; R47 generalizes it), R46 (name-vs-binding is one rung of this ladder inside a code analyzer), R51 (climbing this ladder fixes WHICH object the name denotes at the moment of the check; it does not bind the decision to that object — the interval between the resolution and the use is R51's, and an R47-discharged path guard is exactly where R51 hides). **Reviewer action**: for every predicate in the diff that decides on an input string, name the interpreter that ultimately gives that string meaning and check whether the predicate consults it; a chain of pattern matches enumerating spellings is the finding, and the count of rounds it has already grown by is the severity evidence. | Major; Critical when the surface-form check is the control protecting a security boundary (containment or traversal, authz, an injection sink, a sandbox edge) — every unenumerated spelling is a fail-open bypass |
