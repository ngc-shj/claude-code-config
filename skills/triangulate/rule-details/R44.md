# R44 — Gate exit status read through a lossy or identity-less channel

This file contains the full normative procedure for `R44`. The compact row in `../common-rules.md` is only its routing summary.

## Full rule

| ID | Pattern | Procedure | Severity if missed |
|---|---|---|---|
| R44 | Gate exit status read through a lossy or identity-less channel | When a command's exit status is the evidence being judged — a test suite, a check hook, a pre-PR/CI gate, a guard script — the judged status MUST be the command's own, never a pipeline aggregate. Piping a gate through a pager/filter (`head`, `tail`, `grep`) makes the pipe tail's exit status the observed one, so a failing gate reads green and the failure is silently passed over. Run the gate unpiped and test its status directly; when output must be truncated, redirect to a file and inspect the file afterwards, or capture the gate's own status (`pipefail` / `PIPESTATUS`-style) before any filter. Applies to every verification moment: phase gates, mutation-proof observations, subagent-reported check runs (pairs with R21 — a piped gate invocation in a verification transcript is not evidence of PASS; pairs with RT7 — a gate whose status is never observed is a gate that cannot fail). **Concurrent-dispatch identity sub-clause**: a pipeline corrupts a status's VALUE; concurrent dispatch corrupts its OWNER — the right status attributed to the wrong unit, which reports a failing gate as passing and a passing one as failed. When a verdict is derived from a concurrent unit's exit status, read that status from a per-unit handle keyed by the unit's own identity; a "wait for any / next completion" primitive carries no identity, so it is a throttle only and its return value must be discarded — binding it to the dispatch loop's current index is a fabricated join. Relatedly, never branch on a status value a supervised child can itself produce: a supervisor bookkeeping sentinel that collides with a real exit code (a missing-interpreter or command-not-found status doubling as "no such job") fails open exactly on environment drift. **Reviewer action**: for each step that concludes PASS from a command's result, confirm the concluding exit status came from the gate command itself — not from a pipeline around it, and not from a completion primitive that never named which unit finished. | Major (Critical when the masked gate guards a security invariant) |
