# R4 — Event/notification dispatch gaps

This file contains the full normative procedure for `R4`. The compact row in `../common-rules.md` is only its routing summary.

## Full rule

| ID | Pattern | Procedure | Severity if missed |
|---|---|---|---|
| R4 | Event/notification dispatch gaps | When mutations are added, verify ALL similar mutation sites dispatch the corresponding event. **Mechanical detection**: `bash ~/.claude/hooks/check-event-dispatch.sh [base-ref]` enumerates every named function per changed file at a valid declaration depth (top-level / class-body / Go-receiver / Python / Ruby class) and classifies each as a mutation site via 3-axis OR: (1) name has a mutation verb prefix (`create`/`update`/`delete`/`cancel`/`approve`/`revoke`/`archive`/`mark`/`grant`/`expire`/...); (2) name is an HTTP mutation verb — `POST`/`PUT`/`PATCH`/`DELETE` (with optional `handle` prefix), catching NextJS / Hono / Express route handlers; (3) body contains a DB-write primitive call — Prisma / Mongoose / Sequelize / TypeORM / Drizzle / Knex `.create/.delete/.upsert/.insert/.save/.remove(...`, Prisma-style `.update({...})`, raw SQL `INSERT/UPDATE…SET/DELETE FROM`. Each mutation site is then scanned for a dispatch verb (`emit`/`publish`/`dispatch`/`notify`/`broadcast`/`fire`/`sendEvent`/...; project helpers via `EXTRA_DISPATCH_VERBS`). Two peer-group scopes are evaluated: **(file, scope)** for class methods / multi-handler files / service modules, AND **`<dir:parent-of-verb-dir>`** for route files at leaf verb directories — when a `route.<ext>` file is the sole source file in its parent directory (no subdirectories, no other source siblings), sibling `route.<ext>` files under the same grandparent directory are treated as cross-file peers. The leaf-verb-dir gate is a structural filesystem check, not a path-component-count heuristic, so entity-direct routes like `<entity>/route.<ext>` whose parent dir holds nested resource subdirectories are NOT promoted. Major fires when a NEW non-dispatching mutation shares either peer group with ≥1 dispatching sibling. Auto-suppression: transitive dispatch (calls another same-file mutation that dispatches), body-edits (name appears on diff `-` lines), JS standard-library shapes (`Object.create` / `Set.delete` / `Map.delete` / etc.). The hook is silent for cross-file mutation families that span beyond the leaf-verb-dir convention — directory-level R4 review is still manual there | Major |
